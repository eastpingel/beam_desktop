# Beam Studio

Beam Studio is a Python desktop app for exploring beam reactions, shear, bending moment, elastic deflection, and preliminary screening checks. It supports simply supported beams and cantilevers, editable loads and section properties, JSON save/open, CSV data export, and PDF reports. Results are for preliminary screening, not final structural design approval.

## Requirements

Use Python 3.10 or later with Tkinter available. The app uses only Python standard-library packages; there are no packages to install with pip. On some Linux distributions, Tkinter may need to be installed separately through the system package manager.

## Start the app

From the project directory, run:

```powershell
python app.py
```

On Windows, `py app.py` can also be used.
